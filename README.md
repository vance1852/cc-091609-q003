# 中药处方安全复核

门诊中药房发药前的处方安全复核服务。系统围绕剂量与单位标准化、别名归一、
配伍禁忌（十八反）、特殊人群、过敏史、并用药建立**版本化规则**；规则提示
只作为人工复核依据（为何命中、哪些信息尚待核实），放行必须由医师与药师
在当前处方快照上完成双向会签，系统不替代临床判断。

## 模块

- `domain/contracts.py` — 处方快照、规则证据、会签意见（既有契约，未改动）
- `domain/catalog.py` — 饮片目录：别名归一（姜半夏→半夏类、黑顺片→附子）、
  剂量单位折算（克/g/钱/两/分 → 克；无法折算返回 None 交人工核实，不猜测）
- `domain/rules.py` — 版本化规则引擎。每条规则带 `rule_id`/`version`/
  `valid_from`/`source_reference`；同规则同紧急程度的重复命中合并展示，
  全部命中明细与证据完整保留
- `domain/review.py` — 复核服务。医师改方即产生新快照并全量重算；意见只能
  落在当前快照（旧版不可补签、不得沿用）；角色来自签章注册表，不能代签；
  放行闸门要求当前快照上医师说明 + 药师放行的有效双向会签
- `domain/queries.py` — 复核看板：每条提示的来源版本、双方意见、处方演变；
  患者敏感信息按最小范围返回（仅披露被提示实际引用的事实）
- `domain/demo.py` — 按 `fixtures/prescription_review.json` 走完整流程

## 运行

```bash
python3 -m compileall domain          # 语法检查
python3 -m unittest discover -s tests # 28 项测试
python3 -m domain.demo                # 端到端演示（含“旧版放行无法解锁新版”的证明）
```

## 关键不变量（均有测试覆盖）

1. 医师修改任何药味 → 新快照 + 重新计算，旧意见不得沿用；
2. 只有当前快照上的有效双向会签（医师说明 + 药师放行，且不得同人）才能放行；
3. 旧版放行无法解锁新版处方，被取代的旧版自身也不可再调配；
4. 拒绝调配终止本快照流程，须医师修改产生新快照后重启；
5. 同规则同紧急程度的重复命中合并为一条提示，依据不丢；
6. 看板仅返回脱敏患者标识与被提示引用的患者事实。
